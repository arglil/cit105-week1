# CIT 105 Week 1

This repository contains my Module 1 Environment Verification assignment for CIT 105.

## Program

The `main.py` script displays:

- My full name
- The current date
- The Python version being used

## How to Run

1. Open the project in PyCharm.
2. Make sure the project virtual environment is active.
3. Open `main.py`.
4. Run the script.

You can also run the program from the terminal with:

`python main.py`

## Development Environment

- Python 3.14.6
- PyCharm
- Git
- Python virtual environment (`.venv`)
